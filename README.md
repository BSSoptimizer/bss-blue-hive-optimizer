# BSS Blue Hive Optimizer

A Bee Swarm Simulator Blue Hive optimization tool designed to help players improve hive efficiency, collector selection, and honey production.

## Features
- Blue Hive optimization
- Collector comparison
- Hive composition recommendations
- Progression-based recommendations
- Fast and responsive UI
